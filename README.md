# pyspark-sales-etl-pipeline
ETL pipeline developed with PySpark for extracting, cleaning, transforming and processing sales data, with Parquet output using PyArrow.
Tecnología	          Implementación
Python 3.11	          Lenguaje principal
PySpark 3.5.6	        Extracción y transformación
Spark DataFrames	    Procesamiento de datos
PyArrow	              Exportación local a Parquet
Apache Parquet	      Almacenamiento columnar
ETL	                  Arquitectura Extract, Transform, Load
